KARANA INVESTMENT GROUP — HOSTINGER WEBSITE

UPLOAD
1. Open Hostinger hPanel > Websites > Manage > File Manager.
2. Open public_html.
3. Upload every file and the assets folder from this package.
4. Make sure index.html is directly inside public_html.

CONTACT FORM
The form sends inquiries to info@karanainvest.com through submit.php.
After uploading, submit one test inquiry. If it does not arrive, confirm that
PHP mail is enabled for the hosting plan and that info@karanainvest.com exists.
Check the Spam folder during the first test.

FILES
index.html      Main website
styles.css     Website design
script.js      Menu and inquiry forms
submit.php     Basic email form handler
thank-you.html Confirmation page
assets/        Karana logo and banner

SECURITY NOTE
The site describes private partner relationships without publicly offering
securities, quoting returns, or publishing investment terms. Have a securities
attorney review the final public copy before beginning fundraising.
